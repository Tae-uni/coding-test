# Coding Test Prep
## Why I Started
I recently applied to a company I really wanted to join. I passed the resume screening, but did poorly on the CodeSignal General Coding Assessment.

That experience made me realize I need to take coding test prep more seriously. I was disappointed with the result, and I don't want to miss another opportunity for the same reason. I'm using this repository to practice consistently and track my progress, one problem at a time.

## Goal
- Reliably pass a GCA-style assessment: solve **Q1-Q3** fully and get most of the credit on Q4 within 70 minutes

## Plans
- 2-3 problems a day (new problems + review)
- Weekly mock test: 4 unseen problems in 70minutes.
- Language: Python
